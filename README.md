# 제타 익명 게시판

제타 웹 채팅방에 RP 세계관을 바탕으로 한 익명 게시판을 추가하는 Tampermonkey 스크립트입니다. 글을 직접 쓰거나 Gemini로 가상의 게시글과 댓글을 생성할 수 있습니다.
설명 보러가기 : https://casualjh.github.io/zeta-anonymous-board/

## 설치하기

1. 브라우저에 Tampermonkey를 설치하고 활성화합니다.
2. [스크립트 설치하기](https://github.com/casualJH/zeta-anonymous-board/raw/refs/heads/main/zeta-anonymous-board.user.js)를 열고 설치합니다.
3. 제타 웹 채팅방을 열고 메시지가 표시되면 **익명 게시판**을 누릅니다.

## AI 생성 준비

1. **설정 → API 설정**에서 Google AI Studio에서 발급한 Gemini API 키를 입력하고 **키 저장**을 누릅니다. 키와 모델 설정은 모든 채팅방에서 공유합니다.
2. **My → 프로필/커뮤니티 → 제타 프로필 불러오기**를 누릅니다. 유저 프로필 1개와 캐릭터 1명 이상을 선택하고 **프로필 저장**을 누릅니다.
3. 필요하면 **세계관 설정·배경**에 정보를 입력합니다. 커뮤니티 유형과 게시판 이름, 번역, 추가 지침을 확인한 뒤 **커뮤니티 설정 확인**을 누릅니다.
4. 목록에서 **수동 생성**을 눌러 첫 게시글을 생성합니다.

후보가 비어 있으면 채팅방을 다시 열거나 채팅 상단의 플롯 제목을 눌렀다가 돌아오세요. 캐릭터 설명이 비어 있으면 제타에서 캐릭터 프로필 사진을 누른 뒤 다시 불러오세요.

## 게시판 사용

- **글쓰기** · 제목과 본문을 입력하고 **게시글 등록**을 누릅니다.
- **목록** · 최신순, 인기순, 미확인으로 봅니다. 미확인에는 새 글과 마지막 확인 이후 댓글·대댓글이 달린 글이 표시됩니다.
- **글 상세** · 댓글과 대댓글을 등록하고 좋아요를 남깁니다. **AI 반응 생성**으로 현재 글에 대한 반응을 생성할 수 있습니다.
- **자동 갱신** · 첫 수동 생성 이후 자동 ON 상태에서 새 RP 턴에 맞춰 갱신합니다.
- **다시 생성 / 생성 취소** · 최근 생성 결과를 새 응답으로 교체하거나 진행 중인 생성을 중단합니다.

## 커뮤니티

에브리타임, 블라인드, 사내 익명 게시판, 갤러리, 동네 게시판, Reddit, X의 7종을 지원합니다. 유형별로 글감, 말투, 닉네임 형식이 달라집니다.

**+사용자 지정**에서 커뮤니티 이름, 게시판 이름, 강조색, 소개와 말투 지침을 지정할 수 있습니다. 유형을 변경해도 기존 커뮤니티의 글과 주민 기록은 보존됩니다.

## 설정과 데이터

| 탭 | 주요 기능 |
| --- | --- |
| 기본 설정 | 라이트·다크·기기 설정, 창 배율 75~150%, AI 생성 수, 참여 표시, 작성자 댓글 강조, 실제 시간 또는 RP 시간 표시 |
| 주민·닉네임 | 내 닉네임 자동 생성 또는 직접 설정, 고정 주민 이름 수정 |
| 데이터 관리 | 현재 채팅방의 JSON 백업·복원, 커뮤니티·채팅방별 초기화 |

JSON 가져오기에서 **합치기** 또는 **덮어쓰기**를 선택할 수 있습니다. Gemini API 키는 JSON 백업에 포함되지 않으며 초기화해도 유지됩니다.

## Gemini에 전달되는 정보

AI 기능 사용 시 최근 대화 일부, 선택한 프로필·세계관, 관련 게시판 기록이 Gemini에 전달됩니다. 생성과 모델 호출 확인에는 API 할당량이 사용될 수 있습니다.
